# Muse 向けプロンプト：独自ドメインの購入と紐づけ

以下をそのまま Muse に貼ってください。

---

あなたには、私が独自ドメインを1つ買って、公開済みのWebサイトに紐づけるまでを、画面を見ながら一緒に進める案内役をお願いします。私はドメインを買うのが初めてで、操作は主に iPhone のブラウザで行います。

## 状況

- 「PROCESSHOT」という名前のWebサイトを公開済みです。飲んだコーヒーの写真に精製プロセスを重ねた画像を作る、無料のツールです。
- いまのURLは https://tamagohachi.tamagohachi373.workers.dev です。Cloudflare の Workers で動いていて、Worker の名前は `tamagohachi` です。
- Cloudflare のアカウントは持っていて、ダッシュボードにログインできます。
- サイトのコードは Claude Code が管理しています。ドメインを紐づけてもコードの変更は不要だと聞いています。

## やりたいこと

1. `processhot.com` を Cloudflare Registrar で購入する。
2. そのドメインを Worker `tamagohachi` にカスタムドメインとして紐づける。
3. `https://processhot.com` でサイトが開くことを確認する。

2026-11-14 の時点で、`processhot.com` は未登録に見えました（登録情報の照会で該当なし）。ただし確定ではないので、購入画面で空きを確かめるところから始めてください。

## 進め方のお願い

- 1回の返信で案内するのは1ステップだけにしてください。私が「できた」か、画面の様子を伝えてから次へ進んでください。
- Cloudflare の画面は表示名や配置がよく変わります。あなたの記憶と私の画面が違ったら、記憶を押し通さず、私に見えている項目名を聞いてから案内し直してください。可能なら Cloudflare の公式ドキュメントで現在の手順を確かめてください。
- 専門用語は、最初に出たときに一言で説明してください。

## 途中で必ず確認してほしいこと

- **価格**：購入前の画面に出る1年分の金額と、更新時の金額。`.com` は年11ドル前後と聞いていますが、実際の表示を一緒に確認してください。大きく違ったら、買う前に止めてください。
- **自動更新**：オンにするかどうかを私に聞いてください。失効すると第三者に取られる可能性があることも教えてください。
- **登録者情報の公開**：氏名や住所が公開の登録情報（WHOIS）に出ない設定になっているかを確認してください。
- **二要素認証**：Cloudflare アカウントで有効かを確認し、無効なら設定を勧めてください。ドメインを持つとアカウントの価値が上がるためです。
- **www の扱い**：`www.processhot.com` も使えるようにするかを私に聞いてください。

## やってはいけないこと

- パスワード、APIトークン、クレジットカード番号をチャットに貼るよう求めないでください。入力は Cloudflare の画面だけで行います。
- 頼んでいない有料オプションや上位プランを勧めないでください。必要なのはドメイン1つだけです。
- `processhot.com` が取れなかった場合、別の名前や別の末尾（`.app` など）を勝手に進めないでください。そこで止めて、候補を挙げたうえで私の判断を待ってください。
- 既存の Worker の設定（ビルド、ブランチ、デプロイコマンド）は変更しないでください。触るのは「ドメイン」の設定だけです。

## 終わったら

次の3点を短くまとめてください。Claude Code に渡します。

1. 紐づけたドメイン（`www` の有無も）
2. `https://processhot.com` をブラウザで開いた結果
3. 自動更新の設定と、次回の更新日
